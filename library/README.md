# سامانه مدیریت کتابخانه مدرسه سلام تجریش — دوره اول\n\nوب‌اپ فارسی برای مدیریت دانش‌آموزان، کتاب‌ها، امانت و بازگشت، دیرکرد، ورود/خروجی Excel و پشتیبان JSON.\n\nبرای اجرای محلی، فایل `app.html` را باز کنید. برای انتشار در Netlify، می‌توانید پوشه `library` را به‌عنوان base/publish تنظیم کنید.\n\nتوجه: این نسخه از `localStorage` استفاده می‌کند و داده‌ها فقط در همان مرورگر/دستگاه ذخیره می‌شوند. برای استفاده گروهی و اطلاعات واقعی مدرسه، به سرور، پایگاه داده مرکزی و احراز هویت نیاز است. فایل `.netlify` را commit نکنید.\n
